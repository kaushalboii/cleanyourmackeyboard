Features

Everything you need.
Nothing you don't.

A laser-focused tool that does one thing perfectly — lets you clean your keyboard safely.

🔒

One-Click Lock

Lock every single key on your keyboard instantly. No settings. No fuss. One button.

⌨️

Live Key Visualizer

See every key on your Mac keyboard laid out in real-time. Track exactly what you're cleaning.

🎨

Premium Dark UI

Glassmorphic dark interface with purple glow accents. Beautiful enough to leave open.

⚡

Instant Unlock

Press the lock button again or use a mouse click to unlock instantly when you're done.

🍏

macOS Native

Built with SwiftUI for macOS 14+. Feels right at home. Uses only what macOS provides.

🆓

Free & Open Source

No subscriptions. No tracking. No ads. Full source on GitHub. Forever free.

How it works

Three steps.
Clean keyboard.

01

Download & Open

Download the .dmg, drag CleanYourMacKeyboard to your Applications folder, and open it.

02

Press Lock Keyboard

Hit the big "LOCK KEYBOARD" button. Every key is disabled immediately. Safe to clean!

03

Clean & Unlock

Wipe those keys freely. Click the button again when done and you're back to normal.
